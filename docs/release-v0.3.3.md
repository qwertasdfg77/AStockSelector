# AStockSelector 0.3.3 开发记录

`0.3.3` 没有单独发布 APK。以下改动与后续新增的两套三阳战法一并收录在 `0.3.4` 正式版本中。

## 本次更新

- 统一新浪和腾讯备用日 K 的未复权价格口径，旧缓存会自动重建一次。
- 只筛选最新 K 线日期精确等于目标收盘日的股票，拒绝旧 K 线和疑似盘中 K 线，失败股票先写入持久失败队列。
- 最低成交额成为全部战法的硬条件；股票主表保留完整有效股票，降低门槛时自动补齐新增范围。
- 零命中快照可复用，增量结果使用批量事务写入。
- 保存筛选参数并稳定保留“新”标记，后台服务不再意外按默认参数重启。
- 修复失败重试、缓存覆盖率、SQLite 增量写入和安装器异常处理。
- 缓存缺口和本地筛选改用目标交易日索引查询，减少刷新前的全量 K 线扫描。
- 股票列表数量异常时自动切换备用源，目标交易日改为多数样本确认。
- 增加缓存、策略和更新测试，并加强构建与签名供应链校验。

## 安装说明

App 会校验 APK 大小和 SHA256，Android 还会校验安装包签名。旧缓存第一次刷新时会因价格口径升级自动重建，过程需要重新下载约 270 个交易日的数据。

本软件只用于学习、复盘和策略研究，不构成投资建议。
